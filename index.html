SecureLens – Privacy Policy

Last updated: 18 November 2026 · Developer: [TOO WEI WAH] · Contact: [tooweiwah@gmail.com]

SecureLens is a browser extension that checks web pages, links, input fields and files for signs of phishing and malware. It uses Claude, an AI model made by Anthropic, to help review what the local checks find. This policy explains what is processed, where it goes, and what is never collected.

What SecureLens never does

  • It never reads or sends what you type into fields (passwords, card numbers, messages). It looks only at the type and attributes of a field, such as “password field”.
  • It never uploads your files. A file you choose is read on your computer. Only its name, type, size, a SHA-256 fingerprint, findings from local checks and, for scripts, a short redacted text sample are used in a scan.
  • It does not sell data, show ads, build advertising profiles, or use data for anything other than the scan you asked for.
  • It has no accounts, and it does not track you across sites.

What is processed when you press Scan

  • Page scan: the page address (with query values and long ids removed), the host name, connection details, and, for Balanced and Thorough scans, a redacted summary of the page: form structure, script hosts, links, visible text excerpts and warning signs. Emails, phone numbers, long numbers and tokens are redacted before sending.
  • Input fields: the kinds and attributes of fields on the page and where each form sends its data. Never the values.
  • Links you type: only the link text. The site is not opened.
  • Downloads and files: the details listed above, and for a folder, only file names, types, sizes and local findings.

Where this goes

To get Claude’s opinion, the redacted scan summary is sent to Anthropic’s Claude API in one of two ways:

  1. No personal key (default): the summary is sent to a small relay service run by the developer on Cloudflare Workers (securelens-relay.securelens-weiwah.workers.dev), which adds the developer’s key and forwards the request to Anthropic. The relay does not store the content of requests or responses. Cloudflare briefly uses your IP address to limit how many requests one visitor can make.
  2. Your own Claude API key (optional): if you add a key in Settings, the summary goes directly from your browser to api.anthropic.com and does not pass through the relay. The key is stored only in your browser (chrome.storage.local).

Anthropic processes these requests under its own terms and privacy policy (anthropic.com/legal/privacy). SecureLens also sends the host name of a site to cloudflare-dns.com to look up its server address, and may request a site’s icon from Google’s icon service to display it. Only the host name is sent in both cases. The logo lookup can be turned off in Settings.

What is stored, and where

  • Scan history (address without query values, verdict, reasons, detector results, time) is stored only in your browser (IndexedDB). It never leaves your computer. You can set how long it is kept, export it, or delete it all in Settings.
  • Settings (theme, language, toggles, and your own API key if you add one) are stored in your browser.

Permissions, and why

  • activeTab, scripting – read the page you choose to scan.
  • Optional access to websites – asked per site, only when you scan a site that needs it.
  • downloads – list recent downloads so you can choose one to check, and notify you when one finishes.
  • storage – save your settings and history in your browser.
  • clipboardRead – the Paste button in the link box.
  • favicon – show site icons.
  • Access to api.anthropic.com, the relay service and cloudflare-dns.com – the services described above.

Children

SecureLens is not directed at children under 13 and does not knowingly collect their information.
